# n8n Weekly Dev Summary Workflow

This workflow automatically generates a weekly narrative summary of GitHub repository activity using the Claude API and delivers it via webhook.

## Setup Instructions

1. **Import Workflow:** Import the `workflow.json` file into your n8n instance.
2. **Configure Credentials:** Add your GitHub API credentials and Claude (Anthropic) API key.
3. **Set Variables:** Edit the `Config` node to set your `github_owner`, `github_repo`, and `language` (EN/FR).
4. **Destination:** Configure the final Discord/Slack webhook node with your target URL.
5. **Activate:** Toggle the workflow to 'Active' to start the weekly cron job (Fridays at 5 PM).

## Features
- Fetches commits, closed issues, and merged PRs.
- Narrative summary generated by `claude-sonnet-4-20250514`.
- Fully configurable via the `Config` node.
